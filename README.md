# Student Performance Analysis — Pluto Academy Internship

## Project Overview
Analysis of 1000 student records to identify factors affecting
academic performance and at-risk students.

## Dataset
Source: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## What I Did
- Explored and cleaned 1000 student records
- Answered 5 factor analysis questions
- Created 6 visualizations
- Identified 188 at-risk students (18.8%)
- Wrote Principal's Report with 3 recommendations

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Google Colab
